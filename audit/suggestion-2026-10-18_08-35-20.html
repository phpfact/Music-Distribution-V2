Har ticket ka level aur priority kaise padhein?

Level scope / implementation ka spread batata hai; priority business urgency aur development order batati hai. L4 ka matlab apne aap critical bug nahi hai.

Level: 1 → 4

L1
Chhota field, filter, copy ya view improvement; limited implementation area.
L2
Ek module ka meaningful feature ya workflow, uski UI/service/tests ke saath.
L3
Multiple modules/panels, ownership rules ya related schema/workflow ko jodne wala change.
L4
Platform foundation: storage, workers, fleet schema, keys, backup ya shared architecture.

Priority: 1 → 4

P1
Production/core completion se pehle decision ya foundation work. Dependencies resolve karke pehle karein.
P2
Agla useful functional release: current module gaps aur first real music workflow. P1 base ke baad.
P3
Growth/scale ke saath karein; actual user volume, partner/business decision ya measured need chahiye.
P4
Optional experiment: pehle customer demand validate karein, phir investment decide karein.

Effort S = chhota focused change; M = several layers wala feature; L = substantial workflow/integration. Yeh relative estimates hain, calendar-day commitments nahi. Security hardening suggestion ko confirmed exploit nahi maana gaya.
